# SWCADRUN 도면 모으기(COLLECT) - 2026-09-30

`SWCADRUN`의 0/6 단계. 워크플로 버전 `260930-xref-collect-2`. 사용자가 XREF 창에서 한 장씩 붙이고 클릭해 놓던 일을 대신한다.

## 왜 XREF인가

사용자가 확인한 이유(2026-09-29): SolidWorks DWG는 파일마다 같은 블록 이름을 0부터 다시 쓴다(`SW_CENTERMARKSYMBOL_0` 중심 표시, `SW_TABLEANNOTATION_0` 표, `DR_표제란_FTAP` 표제란). 복사·붙여넣기로 모으면 먼저 들어온 정의만 남아 다른 도면의 중심선이 중복되고 이상하게 나왔다. XREF 결합(BIND)은 이름 앞에 파일 이름을 붙여 섞이지 않게 한다. 그래서 모으기도 XREF 붙이기 + 결합을 그대로 쓰고, 자동화하는 것은 붙이기와 배치뿐이다.

## 동작

1. 모델 공간이 빈 도면에서 `SWCADRUN`을 실행하면 단계가 `COLLECT`다.
2. Windows 파일 창(`apps/swcad-workflow/swcad_pick_dwgs.ps1`)에서 DWG를 여러 개 고른다. 다른 폴더는 `A`로 더 고른다.
3. 파일 이름 순서(탐색기 방식, 숫자는 값으로 비교)로 줄을 만든다. 도면번호 첫 번호마다 한 줄, 번호 규칙 밖 파일은 마지막에 10장씩.
4. 명령창의 순서를 보고 `YES`를 입력하면 붙인다. 간격 50 mm, 같은 줄은 윗선을 맞춘다.
5. 한 장이라도 실패하면 그 실행에서 붙인 XREF를 모두 떼어 낸다. 메시지는 `swcad_collect_last.txt`에도 쓴다.

## 배치(용지) 공간에만 그려진 도면

221216 감속기 성능 시험기 도면 32장을 로컬 사본으로 확인했다.

| 형식 | 장수 | 도면 위치 |
| --- | --- | --- |
| DWG 2000 (AC1015) | 18 | 모델 공간 |
| DWG 2007 (AC1021) | 14 | 배치 탭 `시트1`만, 모델 공간 0개 |

XREF는 모델 공간만 보여 주므로 14장은 빈 XREF가 된다. 첫 시험에서 XREF가 0개였던 이유다(한 장 실패로 전부 떼어 냄). SolidWorks의 `용지 공간으로 모든 도면 시트 내보내기`로 저장된 도면이다.

사용자 결정(2026-09-30): 자동 변환.

- 고른 원본은 CAD로 열지 않는다. `%LOCALAPPDATA%\SWTitle\collect\<시각>\<n>\`에 같은 파일 이름으로 복사한다.
- 사본을 열어 내용이 있는 배치 탭 하나의 객체(뷰포트 제외)를 `CopyObjects`로 모델 공간에 옮기고, 배치 탭의 원래 객체는 지운 뒤 저장한다. 저장이 만든 `.bak`는 지운다.
- 원본 대신 사본을 붙인다. 파일 이름이 같으므로 `SOURCE_SHEET_*`의 이름과 Layout 이름은 원본 파일명이다.
- 멈추는 경우(`STOP_COLLECT_PAPER_SHEET`): 모델과 배치가 모두 비었을 때, 내용 있는 배치 탭이 둘 이상일 때, 음수 `DIMLFAC` 치수가 있을 때(배치 공간에서만 적용되어 옮기면 값이 바뀜).
- 32장의 치수 `DIMLFAC`는 모두 양수였다(L-Jig 2, 나머지 1). 옮긴 사본의 객체 수는 종류별로 같고 치수 문구(`%%c<>`, `4-M10 Tap THRU` 등)도 같았다.

## GstarCAD 실측

- ObjectDBX(`ObjectDBX.AxDbDocument.24`)는 레지스트리에 있지만 `GetInterfaceObject`와 `vlax-create-object` 모두 실패한다. 그래서 사본을 문서로 연다.
- `Documents.Open`은 가끔(28회 중 2회, 32회 중 1회) 파일을 열어 놓고도 `Expecting object to be local` 오류를 돌려준다. 같은 파일을 다시 열면 "이미 열려 있음" 확인 창에서 멈춘다. 첫 전체 시험이 11번째 변환에서 멈춘 원인이다. 이제 오류가 나면 열린 문서 목록에서 그 파일을 찾아 쓴다.
- `Close`는 곧바로 끝나지 않는다. 다른 도면을 열거나 활성화할 때 끝난다. 그래서 닫은 뒤 호스트 도면을 `Activate`한다. `gc`나 `vlax-release-object`로는 끝나지 않았다.
- `/b`에서 `Documents.Open`한 도면은 활성 도면이 되지 않는다. 호스트가 계속 활성 도면이다.

## 이 프로젝트 도면의 다음 단계 한계

모으기와 XREF 결합까지는 된다. 결합 뒤 단계는 `BLOCKED_NO_SHEETS`다.

- 31장이 SolidWorks 기본 한국어 도면 양식이다. 도면틀, 구역 표시(A~H, 1~12), 표제란(`작성`, `검사`, `승인`, `도면 번호`, `시트 1 OF 1` 등)이 모두 선과 글자다. GMTITLE 단계는 도면틀·표제란 블록(`DR_A3_Outline`, `DR-A3 FROM_HYUN`, `DR_표제란_FTAP` 등)으로 원본 시트를 찾으므로 하나도 찾지 못한다.
- 도면틀 크기: A4 7, A3 5, A2 9, A1 5, A0 3, 사용자 크기 3(06 Base Frame 약 4746x3354, 07 Brake Base Plate 1990x1590, 08 Drive Base Plate는 테두리 선을 찾지 못함). GMTITLE 단계는 A2·A3·A4 위주다.

이 두 가지는 모으기와 별개의 작업이다.
