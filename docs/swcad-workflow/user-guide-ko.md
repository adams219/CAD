# SWCAD Workflow 쉬운 사용 설명서

이 문서는 SolidWorks에서 저장한 여러 DWG를 XREF로 모은 뒤, GstarCAD Mechanical용 GMTITLE·치수 스타일·Layout으로 변환하는 순서를 설명합니다.

> SWCAD Workflow는 독립 실행 프로그램이 아닙니다. 설치 후 GstarCAD Mechanical을 열고 `SWCAD_Workflow_Load.lsp`를 `APPLOAD`해서 사용하는 AutoLISP 도구입니다.

## 전체 순서

```text
원본 DWG 준비
→ SWCAD Workflow 로드
→ 빈 새 도면에서 SWCADRUN: DWG를 골라 XREF로 자동 배치 (직접 배치도 가능)
→ SWCADSTATUS로 상태 확인
→ SWCADRUN을 단계별로 반복
→ SWCADVERIFY로 최종 확인
→ 저장·닫기·재열기 후 한 번 더 확인
```

원본 SolidWorks DWG는 프로그램이 직접 수정하지 않습니다. 첫 변경 전에 별도의 작업본을 선택하게 하므로, 원본과 다른 파일명으로 저장해야 합니다.

## 1. 프로그램 설치

### 1-1. ZIP 전체 압축 풀기

배포받은 `SWCAD-Workflow-0.1.0.zip`을 원하는 폴더에 전부 압축 해제합니다. 폴더 안의 파일을 따로 빼거나 이름을 바꾸지 않습니다.

Windows 탐색기에 `압축된 크기`, `암호 사용`, `비율` 열이 보이면 아직 ZIP 내부를 보고 있는 상태입니다. 이 상태에서는 설치 파일을 실행하지 않습니다.

1. ZIP 파일을 마우스 오른쪽 버튼으로 누릅니다.
2. `모두 압축 풀기`를 선택합니다.
3. 계속 보관할 폴더를 선택합니다. 예: `문서\SWCAD Workflow`
4. 압축이 끝나면 새로 열린 일반 폴더로 들어갑니다.
5. `apps`, `docs`, `src`, `install.ps1`, `Install_SWCAD_Workflow.cmd`가 함께 있는지 확인합니다.

### 1-2. 로더 설치

1. 압축을 푼 폴더에서 `Install_SWCAD_Workflow.cmd`를 한 번 실행합니다.
2. 검은 창에 `설치 준비 완료`가 표시되면 아무 키나 눌러 닫습니다.
3. 같은 폴더에 `SWCAD_Workflow_Load.lsp`가 새로 생성됐는지 확인합니다.

이 과정은 프로그램 파일들의 현재 위치를 로더에 기록합니다. 패키지 폴더를 다른 위치로 옮긴 경우 다시 실행해야 합니다.

### 1-3. GstarCAD에서 LSP 로드

1. GstarCAD Mechanical을 실행합니다. 현재 검증 기준은 GstarCAD Mechanical 2024 Korean입니다.
2. 아래쪽 명령창에 `APPLOAD`를 입력하고 Enter를 누릅니다.
3. 파일 선택 창에서 압축을 푼 패키지 최상위 폴더로 이동합니다.
4. `SWCAD_Workflow_Load.lsp`를 선택하고 `로드`를 누릅니다.
5. 명령창에 SWCAD Workflow가 로드됐다는 메시지가 표시되는지 확인합니다.

정상적으로 로드되면 다음 세 명령을 사용할 수 있습니다.

```text
SWCADSTATUS
SWCADRUN
SWCADVERIFY
```

사용자는 `apps`나 `src` 안의 LSP 파일을 따로 불러오지 않습니다. 항상 패키지 최상위에 생성된 `SWCAD_Workflow_Load.lsp` 하나만 `APPLOAD`합니다.

GstarCAD를 새로 실행하면 LSP를 다시 `APPLOAD`해야 합니다. 매번 로드하기 번거로우면 `APPLOAD` 창의 시작프로그램/Startup Suite 기능에 `SWCAD_Workflow_Load.lsp`를 추가할 수 있습니다. 회사 보안 정책이 있는 PC에서는 CAD 관리자에게 자동 로드 등록을 요청합니다.

## 2. 원본 DWG 준비

- SolidWorks에서 저장한 원본 DWG 파일들을 한 폴더에 모읍니다.
- 나중에 생성되는 Layout 이름은 원본 파일명을 우선 사용하므로 파일명을 미리 정리합니다.
- 자동 배치는 파일 이름 순서를 따릅니다. 순서를 바꾸려면 파일 이름을 바꿉니다.
- 원본 파일은 열어서 분해하거나 PURGE하지 않습니다.
- 다른 XREF가 들어 있는 중첩 XREF 도면은 자동 변환 대상에서 제외됩니다.

## 3. 새 호스트 도면 만들기

여러 원본 도면을 한곳에 모을 빈 도면을 호스트 도면이라고 합니다.

1. GstarCAD Mechanical에서 새 도면을 엽니다.
2. `Model` 탭으로 이동합니다.
3. 원하면 `프로젝트명_XREF_HOST.dwg` 같은 이름으로 먼저 저장합니다. 저장하지 않은 새 도면에서 시작해도 됩니다.

호스트 도면은 원본들을 연결하고 배치하는 용도입니다. 실제 변환을 시작하면 이 호스트도 별도의 작업본으로 한 번 더 저장됩니다.

## 4. 원본 DWG를 XREF로 불러오기

### XREF를 쓰는 이유

SolidWorks DWG는 파일마다 같은 이름의 블록을 씁니다(`SW_CENTERMARKSYMBOL_0` 중심 표시, `SW_TABLEANNOTATION_0` 표, `DR_표제란_FTAP` 표제란 등). 복사·붙여넣기나 INSERT로 한 도면에 모으면 먼저 들어온 도면의 블록만 남아서, 다른 도면의 중심 표시가 엉뚱하게 그려집니다. XREF로 붙인 뒤 결합(BIND)하면 블록 이름 앞에 파일 이름이 붙어 섞이지 않습니다. 그래서 복사·붙여넣기나 INSERT는 쓰지 않습니다.

### 4-1. 자동으로 모으기 (추천)

1. 빈 새 도면에서 `SWCADRUN`을 입력합니다. 단계 표시가 `0/6 도면 모으기`입니다.
2. 파일 선택 창에서 모을 DWG를 고릅니다. 여러 개는 `Ctrl`, `Shift`, `Ctrl+A`로 고릅니다.
3. 다른 폴더의 도면도 넣으려면 명령창에서 `A`를 누르고 다시 고릅니다. 다 골랐으면 `Enter`를 누릅니다.
4. 명령창에 줄별 순서가 표시됩니다. 확인한 뒤 `YES`를 입력합니다.
5. 결과가 `OK_COLLECT_XREFS_PLACED`이면 화면에서 배치를 눈으로 확인합니다.
6. `SWCADRUN`을 다시 입력하면 다음 단계(작업본 저장, XREF 결합)로 넘어갑니다.

배치 규칙은 다음과 같습니다.

- 파일 이름 순서입니다. Windows 탐색기처럼 숫자는 값으로 비교합니다(`Part 2` 다음에 `Part 10`).
- 도면번호의 첫 번호마다 새 줄을 시작합니다. `01-06-05-00_Bearing Unit Housing`은 `01` 줄에 들어가므로, 조립도 `01-00-00-00` 뒤에 그 부품들이 한 줄로 놓입니다.
- 번호 규칙(`01-06-05-00_이름`처럼 숫자를 `-`로 이은 이름)에 맞지 않는 파일은 마지막 줄들에 10장씩 놓습니다.
- 도면 사이 간격은 50 mm이고, 같은 줄의 도면은 윗선을 맞춥니다.
- XREF 축척 1, 회전 0으로 붙입니다.

배치를 다시 하려면 이 도면을 저장하지 말고 닫은 뒤 새 도면에서 다시 시작합니다. 모으기 단계에서 명령창에 나온 내용은 기록 파일 `swcad_collect_last.txt`에도 남습니다. 파일 위치는 명령창 마지막 줄에 표시됩니다.

#### 배치(용지) 공간에만 그려진 도면

SolidWorks에서 `용지 공간으로 모든 도면 시트 내보내기`를 켜고 저장한 DWG는 도면이 배치 탭(예: `시트1`)에만 있고 모델 공간이 비어 있습니다. XREF는 모델 공간만 보여 주므로 그대로 붙이면 빈 도면이 됩니다.

`SWCADRUN`은 이런 도면을 자동으로 처리합니다.

1. 고른 원본 파일은 열지 않고, `%LOCALAPPDATA%\SWTitle\collect\<날짜_시각>\` 아래에 같은 이름의 사본을 만듭니다.
2. 사본을 열어 배치 탭의 내용을 모델 공간으로 옮기고 저장합니다. 이때 도면 창이 잠깐 열렸다 닫힙니다.
3. 원본 대신 그 사본을 XREF로 붙입니다. 파일 이름이 같으므로 Layout 이름도 원본 파일명이 됩니다.

내용이 있는 배치 탭이 두 개 이상이거나, 배치 공간에서만 적용되는 음수 치수 배율(DIMLFAC)이 있으면 옮기면 결과가 달라질 수 있어 `STOP_COLLECT_PAPER_SHEET`로 멈춥니다. 이때는 그 파일을 SolidWorks에서 `용지 공간으로 모든 도면 시트 내보내기`를 끄고 다시 DWG로 저장합니다.

### 4-2. 직접 붙이기

자동 배치 대신 직접 배치할 수도 있습니다. 각 원본 DWG를 모델 공간에 외부 참조로 붙입니다.

1. 명령창에 `XREF`를 입력합니다.
2. 외부 참조 창의 왼쪽 위 `DWG 부착` 또는 `참조 부착` 버튼을 누릅니다.
3. 원본 SolidWorks DWG를 선택합니다.
4. 부착 옵션을 아래 표와 같이 맞춥니다.
5. `확인`을 누르고 모델 공간에서 도면을 놓을 위치를 한 번 클릭합니다.
6. 외부 참조 창에서 상태가 `로드됨`인지 확인합니다.
7. 나머지 원본 DWG도 같은 방식으로 모두 붙입니다.

| XREF 부착 항목 | 설정 |
| --- | --- |
| 참조 형식 | 부착(Attach) |
| 삽입점 화면에서 지정 | 켜기 |
| 축척 화면에서 지정 | 끄기 |
| X 축척 | `1` |
| Y 축척 | `1` |
| Z 축척 | `1` |
| 회전 화면에서 지정 | 끄기 |
| 회전각 | `0` |

원본 경로는 전체 경로나 상대 경로를 사용할 수 있지만, 변환이 끝날 때까지 XREF 상태가 `찾을 수 없음` 또는 `언로드됨`이 되면 안 됩니다.

다음 규칙으로 배치하면 Layout 순서를 알아보기 쉽습니다.

- 도면끼리 겹치지 않도록 간격을 둡니다.
- 출력하려는 순서대로 왼쪽에서 오른쪽으로 놓습니다.
- 여러 줄을 사용하면 위쪽 줄부터 아래쪽 줄 순서로 놓습니다.
- 첫 도면의 왼쪽 아래를 `(0,0)`에 맞추는 것은 선택 사항입니다.
- XREF의 크기나 회전은 바꾸지 않습니다.

프로그램은 사용자가 정한 XREF 위치를 그대로 유지합니다. XREF 위치를 기준으로 최종 도면과 Layout 순서를 계산합니다.

### 이 단계에서 하지 말아야 할 작업

```text
BIND 하지 않기
EXPLODE 하지 않기
PURGE 하지 않기
원본 도면틀이나 표제란을 지우지 않기
XREF 이름을 임의로 바꾸지 않기
```

이 작업들은 `SWCADRUN`이 순서에 맞게 처리합니다.

## 5. 변환 전 상태 확인

모든 XREF를 배치한 뒤 다음 명령을 입력합니다.

```text
SWCADSTATUS
```

이 명령은 도면을 변경하지 않습니다. XREF 수량과 현재 단계, 다음에 실행할 명령을 보여줍니다.

다음과 같은 차단 결과가 나오면 `SWCADRUN`을 반복하지 말고 원인을 먼저 고칩니다.

| 표시 | 뜻과 조치 |
| --- | --- |
| `BLOCKED_UNSUPPORTED_XREF_TRANSFORM` | XREF 축척이 1이 아니거나 회전이 0이 아닙니다. XREF 배치를 수정합니다. |
| `BLOCKED_NESTED_OR_UNREFERENCED_XREF` | 중첩되거나 연결되지 않은 XREF가 있습니다. 원본 구조를 확인합니다. |
| `BLOCKED_NATIVE_GMTITLE_XREF` | 이미 native GMTITLE인 XREF입니다. 자동 분해 대상이 아닙니다. |
| `STOP_COLLECT_PAPER_SHEET` | 배치 공간에만 그려진 도면을 모델 공간 사본으로 바꾸지 못했습니다. 표시된 파일을 SolidWorks에서 `용지 공간으로 모든 도면 시트 내보내기`를 끄고 다시 저장합니다. |
| `BLOCKED_COLLECT_SCRIPT_ACTIVE` | SCRIPT 실행 중에는 파일 선택 창을 열지 않습니다. 명령창에 `SWCADRUN`을 직접 입력합니다. |
| `STOP_SHEET_FORMAT_UNSUPPORTED` | SolidWorks 기본 양식 시트 가운데 자동으로 바꿀 수 없는 것이 있습니다. 아래 "SolidWorks 기본 양식 도면"을 봅니다. |
| `ABORT_`, `ERROR_`, `WARN_` | 같은 명령을 계속 누르지 말고 표시된 원인을 확인합니다. |

모으기 단계가 `STOP_` 또는 `ERROR_COLLECT_`로 끝나면 그 실행에서 붙인 XREF를 모두 떼어 내므로 도면은 바뀌지 않습니다.

정상이고 다음 단계로 `SWCADRUN`을 안내하면 변환을 시작합니다.

## 6. SWCADRUN으로 단계별 변환

다음 명령을 입력합니다.

```text
SWCADRUN
```

첫 변경 시 `다른 이름으로 저장` 창이 열립니다. 반드시 원본이나 호스트와 다른 이름을 지정합니다.

```text
예: 프로젝트명_SWCAD_WORK.dwg
```

이 파일이 실제 변환 작업본입니다. 이후 작업과 저장은 이 파일에서 진행됩니다.

`SWCADRUN`은 전체 작업을 한 번에 끝내는 명령이 아닙니다. 현재 상태에서 안전한 다음 단계 하나를 실행합니다.

| 단계 | 프로그램이 하는 일 |
| --- | --- |
| 0/6 도면 모으기 | 빈 도면에서만: 고른 DWG를 XREF로 붙이고 파일 이름 순서로 배치합니다. |
| 1/6 입력 준비 | XREF 파일명·좌표를 기록하고 BIND/EXPLODE합니다. |
| 1/6 SolidWorks 기본 양식 정리 | 도면틀·표제란이 선과 글자로만 그려진 SolidWorks 기본 양식이면, 그 선·글자를 표제란 값과 함께 임시 블록으로 묶습니다. |
| 2/6 GMTITLE | 용지 크기를 감지하고 DR 도면틀·제목블록을 만들며 기존 표제란 값을 옮깁니다. |
| 3/6 치수 | 치수 스타일과 맞춤공차를 통일하고 원래 치수값을 비교합니다. |
| 4/6 Layout | XREF 배치 순서와 원본 파일명으로 A4 Layout을 만듭니다. |
| 5/6 전체 정리 | 사용하지 않는 블록·레이어·스타일 등 이름 정의를 정리합니다. |
| 6/6 검증 준비 완료 | 모든 변환 단계가 끝났습니다. 이제 별도 명령 `SWCADVERIFY`를 실행합니다. |

한 단계가 끝나고 명령창에 다시 `명령:`이 표시되면 다음 순서로 진행합니다.

```text
SWCADSTATUS
→ 다음 작업이 SWCADRUN인지 확인
→ SWCADRUN
→ 명령 프롬프트가 돌아올 때까지 기다리기
```

완료될 때까지 이 순서를 반복합니다. 도면 상태에 따라 `SWCADRUN` 실행 횟수는 달라질 수 있습니다.

### SolidWorks 기본 양식 도면

SolidWorks 기본 한국어 도면 양식(표제란에 `작성`, `검사`, `승인`, `도면 번호`, `배율:`, `시트 1 OF 1`이 있는 양식)은 DWG로 저장하면 도면틀과 표제란이 블록이 아니라 선과 글자로만 들어갑니다. `SWCADRUN`은 GMTITLE 단계 전에 이런 시트를 한 번 정리합니다.

1. 표제란 칸 이름 17개가 기본 양식 자리에 있는지, 두 겹 테두리가 있는지로 시트를 알아봅니다.
2. 용지 크기는 테두리 크기로 정합니다. 표제란의 크기 칸(`A3`)은 모든 시트에 똑같이 적혀 있어 쓰지 않습니다.
3. 칸 이름 그대로 값을 읽습니다.
   - `도면 번호` 칸 → 도면번호(NR). SolidWorks는 이 칸에 SolidWorks 파일 이름을 넣습니다(예: `Bush Inner`).
   - `제목` 칸 → 도면명(DWG)
   - `배율:` 뒤 → 척도, `재질:` 뒤 → 재질, `수정본` → 개정
   - `작성` 줄의 이름·날짜 → 작성자·날짜, `검사`·`승인` 줄의 이름 → 검도·승인
   - 파일 이름은 쓰지 않습니다. 빈 칸은 위 "표제란 값 옮기기"의 기본값 규칙을 따릅니다.
4. 양식의 선·글자·주석(일반 공차 안내, 디버링 안내)을 모두 임시 블록 두 개(`SWFMT_A3_OUTLINE_01`, `SWFMT_TITLE_01` 같은 이름)로 옮깁니다. 다음 GMTITLE 단계가 이 블록을 새 DR 도면틀·`DR_titlea_3rd`로 바꾸고 임시 블록을 지웁니다.
5. 새 표제란에 칸이 없는 글자(무게, 표면 거칠기, 공차 안내 등)는 옮기지 않고 `swcad_sheet_format_last.txt`에 기록만 합니다.

다음 경우에는 아무것도 바꾸지 않고 `STOP_SHEET_FORMAT_UNSUPPORTED`로 멈추며, 해당 파일 목록을 보여 줍니다.

| 표시 | 뜻과 조치 |
| --- | --- |
| 테두리 모양이 기본 양식과 다름 | 사용자 크기 용지처럼 표제란이 테두리 오른쪽 아래 모서리에 있지 않습니다. SolidWorks에서 A0~A4 표준 크기로 다시 저장하거나, 그 파일을 빼고 새 도면에서 다시 모읍니다. |
| 표준 크기 아님 / 용지 방향 다름 | 용지가 A0~A4가 아니거나, A4가 가로·A0~A3가 세로입니다. DR 도면틀은 A4 세로, 나머지 가로입니다. |
| 도면틀 파일 없음 | A0 도면인데 GstarCAD 도면틀 폴더(`C:\Program Files\Gstarsoft\GstarCAD Mechanical 2024 Korean\Dwg\Format`)에 `DR_A0_Outline.dwg`가 없습니다. `DR_A1_Outline.dwg`처럼 만들어 넣으면 변환됩니다. |
| 도면틀 없음 | 도면틀 블록도 기본 양식도 없는 도면입니다. |
| 잠긴 레이어 | 양식 선·글자가 잠긴 레이어에 있습니다. 잠금을 풀고 다시 실행합니다. |

### 표제란 값 옮기기

GMTITLE 단계는 새 `DR_titlea_3rd`의 11칸을 모두 원본 표제란 값으로 씁니다.

- 원본 표제란이 블록 속성(예: `DR_titlea_3rd`)이면 칸 이름으로 읽고, 일반 글자이면 칸 위치로 읽습니다.
- 글꼴 같은 서식 코드(`\F...;`, `{ }` 등)는 지우고 씁니다.
- 원본에 값이 없는 칸은 다음 값으로 채웁니다.
  - 작성자, 검도, 승인, 척도, 개정, 수량, 재질: `DR_titlea_3rd` 기본값(HS KANG, KS LEE, KS LEE, 1:1, 0, 1, -)
  - 날짜: 변환한 날
  - 도면번호, 도면명: 빈칸. GMTITLE 기본값인 `XXX`와 파일 경로는 쓰지 않습니다.
- 값을 쓴 뒤 11칸을 다시 읽어 비교합니다. 하나라도 다르면 원본 표제란을 지우지 않고 멈춥니다.
- 새 표제란에 해당 칸이 없는 원본 글자(예: SolidWorks 양식의 `Item ref`)는 옛 표제란과 함께 지워집니다. 지운 글자의 내용은 `swcad_title_transfer_apply_last.txt`에 남습니다.
- 옛 표제란 주변은 표제란 안에 있는 선·해치와, 표제란에 닿아 있는 도면틀 테두리 여백의 모서리 표시만 지웁니다. 표제란에 닿기만 한 중심선이나 단면 해치 같은 도면 내용은 남깁니다.
- 옛 표제란·도면틀·표제란 글자가 잠긴 레이어에 있으면 GMTITLE을 만들기 전에 `ABORT_SOURCE_ON_LOCKED_LAYER`로 멈춥니다. 레이어 잠금을 풀고 다시 `SWCADRUN`을 실행합니다.
- 변환 뒤 옛 표제란·도면틀·글자가 남아 있으면 `REVIEW_OLD_TITLE_NOT_DELETED`로 멈춥니다. 로그에 나온 핸들의 객체를 확인해 지운 뒤 진행합니다.

### GMTITLE 창이 나타날 때

자동 선택기가 용지와 제목블록을 선택합니다. 자동 선택 중에는 마우스나 키보드를 건드리지 않습니다.

창이 그대로 남거나 수동 확인을 요구하면 다음 값인지 확인합니다.

```text
용지/도면틀: 감지된 DR_A0_Outline(설치한 경우), DR_A1_Outline, DR_A2_Outline, DR_A3_Outline 또는 DR_A4_Outline
제목블록: DR_titlea_3rd
Frame positioning: ON
Object move: OFF
```

특히 `Object move`가 ON이면 기존 도면 내용이 이동할 수 있습니다. ISO 용지, 다른 제목블록, 잘못된 DR 용지가 선택되어 있으면 확인하지 말고 취소한 뒤 오류 내용을 확인합니다.

### 캐드가 멈춘 것처럼 보일 때

30장 기준 XREF 분해, GMTITLE 변환, 전체 정리 단계에서는 수십 초에서 수분 동안 GstarCAD를 조작하기 어려울 수 있습니다.

- 명령창에 다시 `명령:`이 나타날 때까지 기다립니다.
- `Esc`를 반복해서 누르지 않습니다.
- 화면을 계속 클릭하거나 다른 명령을 입력하지 않습니다.
- 작업 관리자로 강제 종료하지 않습니다.

`ABORT_`, `ERROR_`, `WARN_`, `REVIEW_`가 출력되거나 오랫동안 새 출력이 전혀 없을 때만 로그를 보존하고 원인을 확인합니다.

### 오류가 나거나 `Esc`로 멈췄을 때

GMTITLE 단계에서 오류가 나거나 `Esc`로 멈추면 `SWCADRUN`은 `진행 중지`를 출력하고 끝납니다. 다음 단계로 넘어가지 않습니다.

- 결과는 `ERROR_`로 시작하는 상태입니다. 하위 단계가 결과를 남기지 않았으면 `REVIEW_TITLE_STEP_NO_RESULT`입니다. 결과가 없는 것을 완료로 보지 않습니다.
- 변환 중 잠시 꺼 둔 객체 스냅(OSMODE) 같은 설정은 원래 값으로 되돌립니다.
- 현재 도면은 저장하지 않습니다. 명령창 출력과 로그를 보존하고 원인을 확인합니다.

## 7. 최종 검증

상태가 완료로 표시되면 다음 명령을 실행합니다.

```text
SWCADVERIFY
```

최종 성공 문구는 다음과 같습니다.

```text
SWCADVERIFY_FINAL_OK
```

성공 후 아래 항목도 눈으로 확인합니다.

1. 모델 공간의 모든 도면틀과 제목블록이 정상 위치에 있습니다.
2. 대표 A2, A3, A4 제목블록을 더블클릭했을 때 `속성 블록 편집` 표가 열립니다.
3. 치수값과 공차가 원본과 같습니다.
4. Layout 탭 수가 도면 수와 같습니다.
5. Layout 이름이 원본 DWG 파일명과 맞습니다.

`SWCADVERIFY`는 제목블록 값도 검사합니다. 도면번호 `XXX`, 도면명에 들어간 파일 경로, 서식 코드가 남은 제목블록이 있으면 `SWTITLEVERIFY_WARN_TITLE_VALUES`로 알리고 최종 성공으로 보지 않습니다. 표시된 제목블록을 더블클릭해 원본 도면과 같은 값으로 고친 뒤 다시 검증합니다.

## 8. 저장·재열기 확인

1. 작업본을 저장합니다.
2. GstarCAD에서 작업본을 닫습니다.
3. 작업본을 다시 엽니다.
4. 필요하면 `SWCAD_Workflow_Load.lsp`를 다시 `APPLOAD`합니다.
5. `SWCADVERIFY`를 다시 실행합니다.
6. 다시 `SWCADVERIFY_FINAL_OK`가 나오면 변환이 완료된 것입니다.

## 가장 짧은 실행 체크리스트

```text
[ ] SWCAD_Workflow_Load.lsp APPLOAD
[ ] 빈 새 도면에서 SWCADRUN → DWG 고르기 → YES
    (직접 배치할 때: XREF 축척 1, 회전 0, 출력 순서대로 겹치지 않게)
[ ] 배치를 눈으로 확인
[ ] SWCADSTATUS
[ ] SWCADRUN, 작업본을 다른 이름으로 저장
[ ] SWCADSTATUS → SWCADRUN 반복
[ ] SWCADVERIFY_FINAL_OK 확인
[ ] 저장·닫기·재열기 후 SWCADVERIFY_FINAL_OK 재확인
```

문제가 생기면 원본 DWG를 직접 수정하지 말고 작업본의 명령창 출력과 오류 문구를 보존합니다.
