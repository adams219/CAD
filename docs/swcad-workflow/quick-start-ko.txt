SWCAD Workflow 처음 사용하기
==============================

[가장 먼저 확인]

SWCAD Workflow는 단독으로 실행하는 프로그램이 아닙니다.
GstarCAD Mechanical 안에서 LSP를 불러와 사용하는 도구입니다.

Windows 탐색기에 "압축된 크기", "암호 사용", "비율"이 보이면
아직 ZIP 파일 내부입니다. 그 화면에서 설치 파일을 실행하지 마세요.


1. ZIP 압축 풀기
----------------

1) SWCAD-Workflow-0.1.0.zip을 마우스 오른쪽 버튼으로 누릅니다.
2) "모두 압축 풀기"를 누릅니다.
3) 계속 보관할 폴더를 선택합니다.
   예: 문서\SWCAD Workflow
4) 압축을 푼 일반 폴더를 엽니다.
5) apps, docs, src 폴더와 Install_SWCAD_Workflow.cmd가 함께 있는지 확인합니다.

폴더나 파일을 따로 빼거나 이름을 바꾸지 마세요.


2. 설치하기
-----------

1) 압축을 푼 폴더의 Install_SWCAD_Workflow.cmd를 더블클릭합니다.
2) 검은 창에 "설치 준비 완료"가 표시되는지 확인합니다.
3) 아무 키나 눌러 검은 창을 닫습니다.
4) 같은 폴더에 SWCAD_Workflow_Load.lsp가 생겼는지 확인합니다.

패키지 폴더를 다른 위치로 옮기면 Install_SWCAD_Workflow.cmd를 다시 실행하세요.


3. GstarCAD에서 프로그램 불러오기
--------------------------------

1) GstarCAD Mechanical을 실행합니다.
2) 아래 명령창에 APPLOAD를 입력하고 Enter를 누릅니다.
3) 압축을 푼 패키지 폴더로 이동합니다.
4) SWCAD_Workflow_Load.lsp를 선택하고 "로드"를 누릅니다.

중요:
- SWCAD_Workflow_Load.lsp 하나만 APPLOAD합니다.
- apps나 src 폴더 안의 LSP는 사용자가 따로 불러오지 않습니다.
- GstarCAD를 새로 실행하면 다시 APPLOAD해야 합니다.
- 자동 로드를 원하면 APPLOAD의 Startup Suite에 이 로더를 등록합니다.

정상적으로 로드되면 아래 명령을 사용할 수 있습니다.

  SWCADSTATUS  현재 상태 확인, 도면 변경 없음
  SWCADRUN     다음 변환 단계 하나 실행
  SWCADVERIFY  최종 결과 확인, 도면 변경 없음


4. 변환할 원본 DWG 준비
-----------------------

1) SolidWorks에서 저장한 원본 DWG들을 한 폴더에 모읍니다.
2) 파일명은 최종 Layout 이름으로 사용되므로 미리 정리합니다.
3) 원본 DWG를 직접 EXPLODE, BIND, PURGE하거나 도면틀을 지우지 않습니다.
4) 원본 DWG 안에 또 다른 XREF가 들어 있는 중첩 구조는 사용하지 않습니다.


5. 새 호스트 도면 만들기
------------------------

1) GstarCAD에서 새 빈 도면을 엽니다.
2) Model 탭으로 이동합니다.
3) 프로젝트명_XREF_HOST.dwg 같은 이름으로 먼저 저장합니다.

호스트 도면은 여러 원본 DWG를 XREF로 모으는 빈 도면입니다.


6. XREF로 원본 DWG 불러오기
---------------------------

1) 명령창에 XREF를 입력합니다.
2) 외부 참조 창에서 "DWG 부착" 또는 "참조 부착"을 누릅니다.
3) 원본 DWG를 선택합니다.
4) 아래 값을 확인합니다.

   참조 형식: 부착(Attach)
   삽입점 화면에서 지정: 켜기
   축척 화면에서 지정: 끄기
   X/Y/Z 축척: 1 / 1 / 1
   회전 화면에서 지정: 끄기
   회전각: 0

5) 확인을 누르고 모델 공간에서 놓을 위치를 클릭합니다.
6) 외부 참조 상태가 "로드됨"인지 확인합니다.
7) 모든 원본 DWG에 반복합니다.

배치 규칙:
- 도면끼리 겹치지 않게 놓습니다.
- 출력 순서대로 왼쪽에서 오른쪽으로 놓습니다.
- 여러 줄이면 위쪽 줄부터 아래쪽 줄로 놓습니다.
- 첫 도면을 0,0에 놓는 것은 선택 사항입니다.
- XREF 축척과 회전은 변경하지 않습니다.

이 단계에서 BIND, EXPLODE, PURGE는 하지 않습니다.


7. 변환 시작
------------

1) SWCADSTATUS를 입력합니다.
2) 다음 작업으로 SWCADRUN이 표시되면 SWCADRUN을 입력합니다.
3) 처음 "다른 이름으로 저장" 창이 나오면 원본과 다른 이름을 선택합니다.

   예: 프로젝트명_SWCAD_WORK.dwg

4) 명령창에 다시 "명령:"이 표시될 때까지 기다립니다.
5) 아래 순서를 반복합니다.

   SWCADSTATUS
   → 다음 작업 확인
   → SWCADRUN
   → 명령 프롬프트가 돌아올 때까지 기다리기

SWCADRUN은 한 번에 모든 일을 끝내지 않고 아래 단계를 하나씩 처리합니다.

  1/6 XREF와 시트 묶음 준비
  2/6 GMTITLE 도면틀·제목블록 변환
  3/6 치수 스타일·맞춤공차 통일
  4/6 원본 파일명 Layout 생성
  5/6 사용하지 않는 이름 정의 정리
  6/6 최종 검증 준비 완료


8. GMTITLE 창이 보일 때
----------------------

자동 선택기가 동작하는 동안 마우스와 키보드를 건드리지 마세요.
창이 남거나 수동 확인을 요구하면 아래 값을 확인합니다.

  용지: 감지된 DR_A2_Outline, DR_A3_Outline 또는 DR_A4_Outline
  제목블록: DR_titlea_3rd
  Frame positioning: ON
  Object move: OFF

ISO 용지, 다른 제목블록 또는 Object move ON이면 확인하지 말고 취소합니다.


9. 캐드가 멈춘 것처럼 보일 때
-----------------------------

30장 도면은 단계에 따라 수십 초에서 수분이 걸릴 수 있습니다.

- "명령:"이 다시 나타날 때까지 기다립니다.
- Esc를 반복해서 누르지 않습니다.
- 화면을 계속 클릭하거나 다른 명령을 입력하지 않습니다.
- 작업 관리자로 강제 종료하지 않습니다.


10. 완료 확인
-------------

1) 6/6 최종 검증 준비 완료가 표시되면 SWCADVERIFY를 입력합니다.
2) 아래 문구를 확인합니다.

   SWCADVERIFY_FINAL_OK

3) 작업본을 저장하고 닫습니다.
4) 작업본을 다시 엽니다.
5) 필요하면 SWCAD_Workflow_Load.lsp를 다시 APPLOAD합니다.
6) SWCADVERIFY를 다시 실행합니다.
7) 다시 SWCADVERIFY_FINAL_OK가 나오면 완료입니다.

눈으로 확인할 항목:
- 대표 A2/A3/A4 제목블록 더블클릭 시 "속성 블록 편집" 표가 열림
- 치수값과 공차가 원본과 같음
- Layout 수가 도면 수와 같음
- Layout 이름이 원본 DWG 파일명과 맞음


11. 문제가 생겼을 때
--------------------

- "알 수 없는 명령"이 나오면 SWCAD_Workflow_Load.lsp를 다시 APPLOAD합니다.
- 내부 LSP를 찾지 못하면 패키지 폴더를 원래대로 두고 설치 CMD를 다시 실행합니다.
- XREF가 "찾을 수 없음"이면 원본 DWG 경로를 복구하고 다시 로드합니다.
- ABORT_, ERROR_, WARN_가 나오면 SWCADRUN을 계속 누르지 않습니다.
- SWCADVERIFY_FINAL_FAIL이 나오면 임의로 PURGE하거나 객체를 삭제하지 않습니다.
- 문제 도면은 원본이 아니라 작업본에서 확인합니다.
